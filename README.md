# ASUS PD 限充不断流工具

用于 ASUS ROG 幻16 / Zephyrus G16（2023，GU603VV）达到电池充电上限后，USB-C PD 输入掉到 0 W、电脑改用电池供电的问题。

在维护者的 GU603VV / BIOS 315 上，原方案（17000 mV）开启后 PD 输入恢复至约 40 W 以上，电池电流由约 2.8–3.0 A 放电降至约 15–27 mA。

## 使用

1. 下载仓库 ZIP 并解压，双击 **PD限充不断流开关.bat**，允许管理员权限。
2. 点击 **开启修复**。关闭面板后，后台守护继续运行。
3. 点击 **关闭并恢复出厂**，停止守护并恢复 EC 的充电目标。

勾选面板中的“开关机保护”后，当前用户登录时会自动启动守护。更换脚本版本或路径前，先用旧面板关闭修复，再启动新目录中的脚本。

脚本通过华硕 `IecToolkitInterface` 访问 EC，无需安装第三方驱动。已验证设备为 GU603VV / BIOS 315；其他机型的 EC 地址可能不同，请勿直接套用。

## 工作方式

仅在 `PDIN=1`、`ACIN=0`、`State=6` 时维持以下目标：

- `0x14` 为零时写入 `0x0040`。
- `0x15` 与 16400 不一致时写入 **16400 mV**。

这是运行时寄存器调整，不刷写 BIOS。实际供电效果可通过外部功率计与电池电流观察。[调查记录](docs/INVESTIGATION.md)列出实测和控制链线索。

## 充电电流限制的原理

`0x14` 设定充电电流的调节上限，芯片通过电流采样和反馈控制充电过程；实际电池电流还受电压目标、电池状态及负载影响。脚本中的“64 mA”是 `0x0040` 的标称解释，并非持续向电池充入64 mA，也不是整机 PD 输入电流的限制。

本机试验中，保持 `0x14=0`、单独提高电压目标仍持续放电；使用 `0x0040` 并维持电压目标后，PD 恢复供电。因此本方案沿用这一已试用参数。具体原理、参数换算和试验对照见[调查记录](docs/INVESTIGATION.md#充电限流原理与参数选择)。

## 已知问题：电池可能缓慢续充

本方案通过 `0x14=0x0040` 保留非零充电目标来维持 PD 供电，电池可能继续接受小电流，电量逐渐超过 MyASUS / G-Helper 设置的上限。

当前电压目标为 **16400 mV**。实际稳定电量随电池状态和负载变化，以设备电流和 SOC 读数为准。16400 mV 版本的真机效果待复测。
